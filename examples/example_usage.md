# 抖音标题生成器使用示例

## 示例1：添加标题示例

**用户输入：**
```
这些标题太火了！收藏一下：
1. 3个技巧让你的视频播放量翻10倍🔥
2. 千万不要这样做！99%的人都踩过这个坑😱
3. 月入5W的秘密，就藏在这3个字里💰
4. 为什么美妆博主都爱用这款产品？真相让人震惊💥
5. 超级实用！新手必看的5个拍摄技巧✨
```

**处理结果：**
- 自动识别并提取5个标题
- 保存到默认类别（如"general"）或根据上下文分类
- 更新标题库用于后续分析和生成

## 示例2：生成新标题

**用户输入：**
```
帮我生成一些关于美食的爆款标题
```

**预期输出：**
1. **美食探店的3个绝招，让你的视频播放量翻倍🔥** - 适用于美食探店类内容
2. **千万不要这样吃！99%的人都不知道的健康隐患😱** - 适用于健康饮食提醒
3. **月入5W的秘密，就藏在这家小店的3个字里💰** - 适用于店铺推荐内容
4. **为什么这家餐厅这么火？真相让人震惊💥** - 适用于热门餐厅揭秘
5. **超级实用！家庭厨房的5个必备技巧✨** - 适用于家庭烹饪教程

## 集成示例：与利润计算器联动

当用户同时使用两个技能时：

**用户输入：**
```
商品名称 | 销售数量 | 单价 | 退款数量
美妆套装 | 200 | 199 | 10
护肤精华 | 150 | 299 | 8

帮我为这些高利润商品生成爆款标题
```

**处理流程：**
1. 利润计算器分析出美妆套装和护肤精华是高利润商品
2. 标题生成器接收"爆款标题"触发词
3. 基于商品类别（美妆/护肤）生成针对性标题
4. 返回专门针对这些商品的营销标题建议
